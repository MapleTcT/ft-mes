# BPI Event Contracts

This module is the versioned boundary shared by the JetLinks exporter, Flink jobs, the BPI service,
and the Java 8 MES adapter. It intentionally compiles to Java 8 bytecode while remaining part of the
Java 17 BPI build lane.

## Phase 0/1 rules

- Protobuf field numbers in `bpi_events_v1.proto` are immutable after publication.
- Existing fields may not be renamed, removed, renumbered, or have their wire type changed.
- New fields must use new numbers and remain optional under proto3 semantics.
- A malformed envelope is quarantined; a malformed point rejects only that point.
- `points=[]` is a valid empty fact and must never be interpreted as a numeric zero.
- `sequence` and `source_epoch` use the full protobuf `uint64` range, including a zero-based first value.
- START and END candidate keys must be generated by `CandidateKeyFactory`.
- Phase 1 candidates are observations only and must not mutate WOM, QCS, or WMS.

Run `make bpi-contracts-test` from the repository root. The compatibility test compares the generated
descriptor with `src/test/resources/compatibility/bpi-events-v1.fields`; intentional compatible
additions require a reviewed baseline update. The packaged JAR carries the generated descriptor at
`META-INF/protobuf/bpi-events-v1.desc` for registry publication and non-Java consumers.
